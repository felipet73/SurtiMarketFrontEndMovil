# Aplicación Móvil Gamificada para SurtiMarket

## 📱 Descripción del Proyecto
Esta es una aplicación móvil diseñada específicamente para SurtiMarket, situada en la comunidad de Cañar. Su objetivo principal es fomentar hábitos de sostenibilidad en los usuarios mediante la implementación de un sistema de gamificación. 

A través de dinámicas, retos y recompensas, la aplicación busca incentivar prácticas ecológicas y de consumo responsable, generando un impacto positivo en el medio ambiente a través de la interacción diaria con la plataforma.

## 🛡️ Estado del Repositorio
Este repositorio contiene el código fuente del frontend móvil y ha sido auditado para asegurar su calidad estructural
